# Chain Restaurant Sales Analysis | 连锁餐饮门店数据分析
> Python数据分析实战项目，面向数据分析师求职作品集

## 📌 项目背景
连锁餐饮门店销售数据挖掘，从原始订单数据中清洗、计算核心经营指标，定位客流低谷、爆款菜品、客群特征，输出可落地的门店运营优化建议。

## 🛠️ 技术栈
Python | Pandas | Matplotlib | Jupyter Notebook
数据处理：缺失值清洗、异常值过滤、衍生指标计算
可视化：时段客流、营收分布、菜品销量结构、客单价分布

## 📁 文件结构
- `restaurant_analysis.ipynb`：完整可复现代码（数据清洗、计算、绘图全流程）
- `restaurant_analysis_report.html`：导出完整可视化报告（含全部图表+结论）

## 📊 核心分析指标
总营收、订单量、客单价、时段客流分布、菜品销量TOP、复购特征
## 💡 分析结论&业务建议
1. 识别客流低谷时段，建议针对性推出下午茶/晚市套餐拉动客流
2. 区分高毛利爆款与引流款菜品，优化菜单陈列和备货
3. 高峰时段订单集中，可提前做好人力排班预案
