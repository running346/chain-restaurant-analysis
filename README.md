# 连锁餐饮门店经营数据分析
> 数据分析实战项目，基于 Python Pandas、Matplotlib 完成清洗、指标计算、可视化与经营洞察

## 📌 项目背景
模拟连锁餐饮门店销售数据集，围绕门店营收、客单价、订单量、时段客流、品类销售开展分析，定位经营问题，输出可落地的运营建议。

## 🛠️ 技术栈
- Python：Pandas 数据清洗、分组聚合、指标统计
- Matplotlib：多维度可视化（趋势图、分布图）
- Jupyter Notebook：完整分析流程，附带 HTML 静态报告

## 📂 文件说明
- `项目一包装快照.ipynb`：完整可运行分析代码
- `项目一包装快照.html`：导出的分析报告，可直接分享给面试官查看

## 📊 分析内容
1. 数据清洗：缺失值、异常值处理，格式统一
2. 核心指标：总营收、订单量、平均客单价
3. 时间维度：早中晚时段销售分布、日营收趋势
4. 品类维度：菜品销量与贡献占比
5. 结论与优化建议：引流时段、主推菜品、库存优化方向

## 💡 项目收获
熟悉从原始数据 → 清洗 → 探索分析 → 可视化 → 业务结论的完整数据分析链路，训练业务视角，不只输出图表，而是产出能支撑运营决策的结论。
