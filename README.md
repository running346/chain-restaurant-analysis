# Chain Restaurant Sales Analysis｜连锁餐饮门店数据分析
> Python数据分析实战项目，数据分析师求职作品集

## 📌 项目背景
基于连锁餐饮门店订单销售原始数据，完成全流程数据分析：数据清洗、指标计算、多维度可视化，挖掘门店营收规律、客流特征与菜品销售情况，输出可落地的门店运营优化方案。

## 🛠️ 技术栈
Python | Pandas | Matplotlib | Jupyter Notebook
- 数据预处理：缺失值、异常值处理，衍生指标构造
- 可视化分析：时段客流、营收分布、菜品销量、客单价分析

## 📁 文件结构
- `restaurant_analysis.ipynb`：完整可复现代码（数据清洗、指标计算、绘图全流程）
- `restaurant_analysis_report.html`：导出完整可视化报告（含全部图表+分析结论）

## 📊 核心分析指标
总营收、订单量、客单价、时段客流分布、菜品销量TOP、复购特征

## 💡 分析结论&业务建议
1. 识别客流低谷时段，建议针对性推出下午茶/晚市套餐拉动客流
2. 区分高毛利爆款与引流款菜品，优化菜单陈列与备货策略
3. 高峰时段订单集中，提前制定人力排班预案，提升出餐效率
